# FormulAI Client

Frontend application built with React, TypeScript, and Vite.

## Scripts

Run these commands from the `client/` directory:

```bash
pnpm dev
```

Starts the Vite dev server.

```bash
pnpm build
```

Builds the production bundle.

```bash
pnpm build:prod
```

Builds the production bundle using the explicit `production` mode.

```bash
pnpm start
```

Serves the built app with Vite preview.

```bash
pnpm preview
```

Alias for previewing the built app.

```bash
pnpm test
```

Runs tests with Vitest.

## From Workspace Root

You can also run client scripts from the repository root:

```bash
pnpm --filter client dev
pnpm --filter client build
```
